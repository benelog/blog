= Checking JCIP-Style Annotations with SpotBugs and Error Prone

Example for the 'What Static Analysis Tools Check' section of https://tech.benelog.net/thread-safety-annotations.html[Documenting and Verifying Thread Safety] (https://blog.benelog.net/thread-safety-annotations.html[Korean version]).
The Error Prone examples fail compilation on purpose, so they live in a separate subproject from the SpotBugs examples.

== Environment

* JDK 25
* Gradle 9.3.1 (Gradle Wrapper included)
* SpotBugs 4.10.4 (Gradle plugin 6.5.11), Error Prone 2.50.0 (Gradle plugin 5.1.1)

== spotbugs Subproject

* link:spotbugs/src/main/java/net/benelog/Memo.java[Memo.java]: `@Immutable` but has a non-final field, so it is reported as `JCIP_FIELD_ISNT_FINAL_IN_IMMUTABLE_CLASS`
* link:spotbugs/src/main/java/net/benelog/Counter.java[Counter.java]: modifies a `@GuardedBy("this")` field without a lock, but only 33% of accesses hold the lock, so it is not reported at the default report level
* link:spotbugs/src/main/java/net/benelog/LockedCounter.java[LockedCounter.java]: the same violation plus more synchronized methods, so 60% of accesses hold the lock and it is reported as `IS_FIELD_NOT_GUARDED`
* link:spotbugs/build.gradle.kts[build.gradle.kts]: SpotBugs plugin settings. Also prints the text report to the console. `-PreportLow` reports low-priority warnings too

[source,bash]
----
./gradlew :spotbugs:spotbugsMain
----

[source]
----
H M IS: LockedCounter.count not guarded against concurrent access; locked 60% of time  Unsynchronized access at LockedCounter.java:[line 16]
M B JCIP: Memo.content should be final since net.benelog.Memo is marked as Immutable.  In Memo.java
----

[source,bash]
----
./gradlew :spotbugs:spotbugsMain -PreportLow
----

== errorprone Subproject

The `@GuardedBy` example comes in three copies of the same code that differ only in the annotation package, and the `@Immutable` example in two.

* link:errorprone/src/main/java/net/benelog/JcipCounter.java[JcipCounter.java]: `@GuardedBy` from `net.jcip.annotations` (original JCIP). Error Prone does not recognize it, so it compiles without errors
* link:errorprone/src/main/java/net/benelog/JsrCounter.java[JsrCounter.java]: `@GuardedBy` from `javax.annotation.concurrent` (JSR-305). Compile error
* link:errorprone/src/main/java/net/benelog/ErrorProneCounter.java[ErrorProneCounter.java]: `@GuardedBy` from `com.google.errorprone.annotations` (Error Prone's own). Compile error
* link:errorprone/src/main/java/net/benelog/JsrMemo.java[JsrMemo.java]: `@Immutable` from JSR-305. Error Prone does not recognize it, so it compiles without errors
* link:errorprone/src/main/java/net/benelog/ErrorProneMemo.java[ErrorProneMemo.java]: Error Prone's own `@Immutable`. The non-final field and the mutable-type field are compile errors
* link:errorprone/src/main/java/net/benelog/ErrorProneRegistry.java[ErrorProneRegistry.java]: Error Prone's own `@ThreadSafe`. Not checked by default, so it compiles without errors
* link:errorprone/build.gradle.kts[build.gradle.kts]: Error Prone plugin settings. `-PthreadSafeCheck` registers the threadsafe-check subproject as a plugin check

[source,bash]
----
./gradlew :errorprone:compileJava
----

== threadsafe-check Subproject

Error Prone 2.50.0 ships the `ThreadSafeChecker` class, but it is not registered in the built-in check list (`BuiltInCheckerSuppliers`), so `-Xep:ThreadSafe` cannot enable it.
This subproject is experimental code that registers link:threadsafe-check/src/main/java/com/google/errorprone/bugpatterns/threadsafety/ThreadSafeCheck.java[ThreadSafeCheck], a subclass of that checker, in `META-INF/services` so that Error Prone loads it as a plugin check.
It depends on 2.50.0 internals, such as the package-private constructor and ServiceLoader's no-argument constructor requirement, so it is not meant for real projects.

[source,bash]
----
./gradlew :errorprone:compileJava -PthreadSafeCheck
----

In addition to the errors above, the following are reported.

[source]
----
ErrorProneRegistry.java:16: error: [ThreadSafe] @ThreadSafe class fields should be final or annotated with @GuardedBy. See https://errorprone.info/bugpattern/ThreadSafe for details.
	private int count;
	            ^
    (see https://errorprone.info/bugpattern/ThreadSafe)
  Did you mean 'private final int count;'?
ErrorProneRegistry.java:17: error: [ThreadSafe] @ThreadSafe class has non-thread-safe field, 'Map' is not thread-safe
	private final Map<String, String> entries = new HashMap<>();
	                                  ^
    (see https://errorprone.info/bugpattern/ThreadSafe)
----
