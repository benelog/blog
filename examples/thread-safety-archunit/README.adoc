= 스레드 안전성 규칙을 ArchUnit으로 검증하는 예제

https://blog.benelog.net/thread-safety-annotations.html[스레드 안전성의 문서화와 검증] 글의 'ArchUnit으로 검증하는 컨트롤러 필드 규칙' 절에서 다룬 예제입니다.

== 개발 환경

* JDK 25
* Gradle 9.3.1 (Gradle Wrapper 포함)
* ArchUnit 1.5.0, Spring Web 7.0.9, JUnit 6.1.3
* JCIP 애너테이션: `com.github.stephenc.jcip:jcip-annotations:1.0-1`

== 구성

* link:src/main/java/net/benelog/report/ReportFormatter.java[ReportFormatter.java] : `@NotThreadSafe` 로 표시한 클래스
* link:src/main/java/net/benelog/report/ReportService.java[ReportService.java] : `@ThreadSafe` 로 표시한 클래스
* link:src/main/java/net/benelog/web/ReportController.java[ReportController.java] : `ReportFormatter` 와 `SimpleDateFormat` 을 필드로 가진 컨트롤러. 규칙을 어기는 예
* link:src/main/java/net/benelog/web/HealthController.java[HealthController.java] : `Clock` 과 `DateTimeFormatter` 만 필드로 가진 컨트롤러. 규칙을 지키는 예
* link:src/test/java/net/benelog/ThreadSafetyArchTest.java[ThreadSafetyArchTest.java] : ArchUnit 규칙 2개
** `@RestController` 클래스의 필드 타입에 `@NotThreadSafe` 가 붙어 있으면 실패
** 필드 타입이 `Format`, `Calendar`, `StringBuilder` 처럼 스레드 안전하지 않은 JDK 타입이면 실패

== 실행

[source,bash]
----
./gradlew test
----

``ReportController``가 규칙을 어기도록 만들어 두었으므로 테스트 2개가 의도적으로 실패합니다. 실패 메시지에서 규칙을 어긴 필드를 확인할 수 있습니다.

[source]
----
Field <net.benelog.web.ReportController.formatter> has raw type annotated with @NotThreadSafe in (ReportController.java:0)
Field <net.benelog.web.ReportController.dateFormat> has raw type JDK의 스레드 안전하지 않은 타입(Format, Calendar, StringBuilder) in (ReportController.java:0)
----
