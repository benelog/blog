= Verifying Thread Safety Rules with ArchUnit

Example for the 'Project-Specific Rules Verified with ArchUnit' section of https://tech.benelog.net/thread-safety-annotations.html[Documenting and Verifying Thread Safety] (https://blog.benelog.net/thread-safety-annotations.html[Korean version]).

== Environment

* JDK 25
* Gradle 9.3.1 (Gradle Wrapper included)
* ArchUnit 1.5.0, Spring Web 7.0.9, JUnit 6.1.3
* JCIP annotations: `com.github.stephenc.jcip:jcip-annotations:1.0-1`

== Contents

* link:src/main/java/net/benelog/report/ReportFormatter.java[ReportFormatter.java]: a class marked `@NotThreadSafe`
* link:src/main/java/net/benelog/report/ReportService.java[ReportService.java]: a class marked `@ThreadSafe`
* link:src/main/java/net/benelog/web/ReportController.java[ReportController.java]: a controller with `ReportFormatter` and `SimpleDateFormat` fields. Breaks the rules
* link:src/main/java/net/benelog/web/HealthController.java[HealthController.java]: a controller with only `Clock` and `DateTimeFormatter` fields. Follows the rules
* link:src/test/java/net/benelog/ThreadSafetyArchTest.java[ThreadSafetyArchTest.java]: two ArchUnit rules
** Fails if the type of a field in a `@RestController` class is annotated with `@NotThreadSafe`
** Fails if a field type is a JDK type that is not thread-safe, such as `Format`, `Calendar`, or `StringBuilder`

== Running

[source,bash]
----
./gradlew test
----

`ReportController` is written to break the rules, so both tests fail on purpose. The failure messages show which fields broke the rules.

[source]
----
Field <net.benelog.web.ReportController.formatter> has raw type annotated with @NotThreadSafe in (ReportController.java:0)
Field <net.benelog.web.ReportController.dateFormat> has raw type JDK types that are not thread-safe (Format, Calendar, StringBuilder) in (ReportController.java:0)
----
